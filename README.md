# QPBot Prime

やっつけで書いたReadmeです。バグ報告、機能要望は直接ご報告いただくか、Githubのissueまで。 \
コードは当面公開しない予定です。Django, python-telegram-botなどで実装されています。

## 利用方法

- Botはこちらから。 https://t.me/qpprime_bot

- まずはイベントを作成する、しないに関わらずBotとの個別チャットで ```/start``` を実行してください。

- イベントを確認する場合は ```/ff``` を実行してください。チャットルームでは短縮版が、個別チャットでは参加表明を行ったイベントの詳細版と参加者リスト、参加ボタンが表示されます。

- イベントは8名集まると通知が出ます。このとき、主催者にメンションが飛び、イベントの開催ボタンが表示されます。

- イベントを開催確定すると、参加と未定を選択した人にメンションが飛びます。

- イベント開始前に通知が出ます。既定は開始1時間前と30分前の2回で、主催者が自由に変更できます（後述）。

- 最後の通知では、参加と未定を選択した人にメンションが飛び、参加者リストとイベントの詳細も表示されます。

- それより前の通知では、主催者にメンションが飛び、イベントの中止ボタンが表示されます。

- イベントの作成は個別チャット内で ```/create``` を実行してください。チャット画面下部のメニューボタン、または ```/create``` 実行後に出るフォームで作成」から、入力フォームで作ることもできます。

- 過去の日時でイベントを作成することはできません。

- チャットから作成する場合、日付に年を入れられないため最長1年後までのイベントが作成可能です。フォームから作成する場合は年を指定できます。

- イベントのタイトルは255文字までです。絵文字も入るよ。

- イベントの詳細は8,192文字までです。URLを入れた場合はプレビューが1つだけ出ます。

- イベント作成者はイベントの各項目の編集、イベントの開催確定、イベントの中止を行うことができます。編集はチャットのボタンからでも、イベントカードの「フォームで編集」からでも行えます。

- Botがいる他のチャットルームにイベントを共有し、参加者を募ることができます（後述）。

### イベントをチャットルームへ転送する

```/fw``` コマンドで、作成したイベントを他のチャットルームへ共有します。

- 転送先のチャットルームに、あらかじめBotを追加しておいてください。

- イベントを作成すると、個別チャットに ```/fw@qpprime_bot <転送用のID>``` の形のコマンドが届きます。タップ、クリックでコピーできます。

- コピーしたコマンドを、転送先のチャットルームで実行してください。個別チャットでは実行できません。

- コマンドの有効期限は10分間です。期限が切れた場合は、イベントカードの「転送」ボタンを押すと新しいコマンドが発行されます。

- 有効期限内であれば、同じコマンドを複数のチャットルームで実行できます。何度でも転送できます。

- 転送に成功すると、そのチャットルームにGoogleカレンダーの予定作成リンクとイベントカード（参加ボタンつき）が投稿され、主催者にも転送されたことが通知されます。

- トピック（フォーラム）のあるチャットルームでは、コマンドを実行したトピックが転送先として記録されます。以降の通知も同じトピックに届きます。

- イベントの変更、開催確定、中止、開始前の通知は、転送したチャットルームにのみ届きます。

### 開始前の通知を変える

作成フォームと編集フォームの「通知」で設定します。主催者だけが変更できます。

- 既定は1時間前と30分前の2回です。どちらも外せます。

- よく使う刻み（1日前 / 6時間前 / 3時間前 / 2時間前 / 1時間前 / 30分前）はボタン1つで足せます。それ以外は時間を入れて足してください。

- 1イベントにつき10件まで、最大7日前までです。

- 1件も残さなければ、開始前の通知は送りません。

- 通知を送った後にイベントの日時を先に延ばした場合、新しい日程で改めて通知します。

### 前に作ったイベントを使い回す

作成フォームの先頭に「前に作ったイベントから」が出ます。自分が主催したイベントが新しい順に5件並び、選ぶとタイトル・詳細・通知の設定が入ります。日付と時刻はそのままなので、決め直してください。

- 中止したイベントも出ます。日を改めて立て直すときに使えます。

- 同じ内容のイベントは1件にまとめて表示されます。

- 5件より前は「もっと見る」でたどれます。

## FAQ

1. Q> チャットでイベント参加ボタンなどを押しても何も反応がない。 \
   A> Botとの個別チャットで ```/start``` を実行してください。実行後はボタンを押したら個別が飛んでくるようになります。

2. Q> 「フォームで作成」「フォームで編集」のボタンが出てこない。 \
   A> これらのボタンは個別チャットでのみ表示されます。グループ内のイベントカードからは出ません。

3. Q> 開始前の通知が来ない。 \
   A> 通知の設定が空になっていないか、編集フォームの「通知」をご確認ください。また、イベントを転送していないチャットルームには通知は届きません。
